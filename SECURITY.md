# Security policy

## Supported versions

Security fixes are made against the latest release compatible with the current Jellyfin ABI. Older plugin builds and unsupported Jellyfin releases may not receive fixes.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through the repository's **Security** tab by opening a private vulnerability report. Do not open a public issue for a vulnerability that may expose a Jellyfin server, media files, credentials, or network services.

Include:

- the affected plugin and Jellyfin versions;
- the platform and inference mode;
- steps to reproduce with synthetic names and paths;
- the expected security impact; and
- any suggested mitigation.

Do not send credentials, API keys, real media, subtitle contents, private addresses, or full configuration files. You should receive an acknowledgement within seven days. Release timing depends on severity, reproducibility, and Jellyfin compatibility.

General bugs and feature requests belong in the public issue tracker after private information has been removed.
