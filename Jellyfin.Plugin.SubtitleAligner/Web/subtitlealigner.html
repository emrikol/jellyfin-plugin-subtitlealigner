Automatic library scan

The scheduled task checks external subtitle sidecars, resumes from saved results, and skips unchanged video/subtitle pairs.

The scheduled task checks every 15 minutes and starts work only while the window is open. A title already in progress is allowed to finish.

Corrected copies

Writes a new .subalign subtitle beside the source and asks Jellyfin to refresh the item. The source is never overwritten. A pre-existing file is changed only when its saved hash proves this plugin created it. Turning this off leaves existing corrected copies in place.

Individual-cue matching

Allows paraphrased translations while still requiring at least two distinctive words in order.
Prevents a nearby paraphrase from being matched to a distant line. Larger uniform errors belong in Shift entire track.
Each cue is still accepted or rejected independently. Close matching helps with transcription and translation differences; it never borrows an offset from another cue.
Uses ordered spelling, word-ending, and low-weight phonetic evidence. Timing must still be nearby and supported by speech detection.
Treats forms such as “walk,” “walked,” and “walking” as closely related.
Helps with names and transcription spelling differences. Phonetic agreement cannot satisfy the phrase threshold by itself.

Timing classifications

For same-language audio with genuine word timing. A directly matched cue inside this band is kept at its authored time.
For subtitles translated from other-language audio. Source-linked segment onset is less precise than genuine word timing, so offsets inside this wider band are treated as already aligned. VAD must independently confirm speech in the segment.

Advanced engine settings

Use a trusted external server for faster inference, or leave it blank to run Whisper on the Jellyfin host. Path overrides are intended for custom installations; FFmpeg normally uses Jellyfin's configured executable.

Trusted networks only. Subtitle Aligner sends extracted audio sections to this server. Standard whisper-server does not provide client authentication. Use an absolute HTTP or HTTPS URL without embedded credentials.
If the external server is unavailable or returns a transient overload or backend failure, Subtitle Aligner retries the current audio section once with the selected local model and keeps using it for the remainder of the run. Contract errors and cancelled work are never retried.

Speech analysis cache

Keep validated, timestamped speech responses on the Jellyfin host so rerunning the same audio does not repeat deterministic model work. The audio itself is not stored.
